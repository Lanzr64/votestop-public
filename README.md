
# Vote Stop Server
中文 | [Engligh](docs/README_en.md)
一个让玩家可以通过投票来关闭服务器的 Minecraft MOD。


## 介绍

Vote Stop Server 是一个 **Minecraft Mod**，允许玩家通过投票来决定是否关闭服务器。当服务器需要重启维护或玩家想结束当前游戏时，可以通过发起投票来让所有在线玩家共同决定。

**核心机制**：需要所有活跃玩家（非 AFK）一致同意才能关闭服务器，确保每个人的意愿都被尊重。



## 功能特色

- **全员一致** — 仅当所有活跃玩家都投赞成票时，服务器才会关闭
- **AFK 检测** — 极低占用的afk监测，只会监测交互事件和聊天事件，只根据tick时间戳判断afk状态
- **开服保护** — 开服后的一段时间内禁止发起投票
- **性能极低** — 几乎没有性能消耗
- **几乎全部可配置** — 所有游戏内消息可通过配置文件自定义，afk监测间隔和广播间隔等都可以配置

## 指令

| 指令 | 描述 |
|------|------|
| `/tyj votestop yes` | 投票赞成关闭服务器 |
| `/tyj votestop no` | 投票反对关闭服务器（将直接取消本次投票） |
| `/tyj votestop` | 和 `/tyj votestop yes` 一致|

> **注意**：任何玩家投反对票都会立即取消整个投票



## 工作原理

1. **投票发起**：玩家输入 `/tyj votestop` 发起投票
2. **检查条件**：系统检查是否已过开服保护期、是否已有进行中的投票
3. **投票进行**：投票开始后，系统会定期广播当前赞成人数和剩余时间
4. **AFK 排除**：系统自动检测挂机玩家，仅统计活跃玩家
5. **结果判定**：
   - ✅ **全员通过** → 服务器关闭
   - ❌ **有人反对** → 投票取消
   - ⏰ **超时未通过** → 投票取消
